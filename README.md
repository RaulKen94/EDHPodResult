## English

### 📌 About the Project
**cEDH Pod Generator** is a lightweight, single-file web application designed to simulate and generate images of **Competitive Elder Dragon Highlander (cEDH)** pods and leaderboards. It runs entirely in the browser without the need for a backend or installation.

### ✨ Features
*   **Commander Search:** Real-time autocomplete using the [Scryfall API](https://scryfall.com/docs/api).
*   **Full Pod Support:** Handles single commanders, partners, backgrounds, and companions.
*   **Two Game Modes:**
    *   **Pod Mode:** Generates a 2x2 grid layout with commander cards, player positions, and a central "Win" or "Draw" outcome banner.
    *   **Leaderboard Mode:** Generates a vertical Top 4 ranking list, complete with custom text notes and adjustable font sizes.
*   **High-Quality Export:** Export the generated layout as a high-resolution PNG (optimized for mobile sharing).
*   **Modern UI:** A sleek, neon-gold and dark-blue aesthetic inspired by modern cEDH tournament overlays.
*   **Mobile Friendly:** Fully responsive and designed to work perfectly on smartphones.

### 🚀 How to Use
1. Download or clone this repository.
2. Open the `index.html` file (or whatever you named your single file) directly in any modern web browser (Chrome, Safari, Edge, Firefox).
3. Search for commanders, select them, and hit the **"📸 Genera e Salva"** (Generate & Save) button to get your image!

*No server, no build tools, no dependencies required.*

### 🛠️ Technologies Used
*   [HTML5 Canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API) for rendering the layout and generating images.
*   [Scryfall API](https://scryfall.com/docs/api) for card data and images.
*   Vanilla JavaScript & CSS.

## Italiano

### 📌 Informazioni sul Progetto
**cEDH Pod Generator** è un'applicazione web leggera (single-file) progettata per simulare e generare immagini di pod e classifiche per **Competitive Elder Dragon Highlander (cEDH)**. Funziona interamente nel browser, senza necessità di un server backend o installazione.

### ✨ Funzionalità
*   **Ricerca Comandanti:** Autocompletamento in tempo reale tramite le [API di Scryfall](https://scryfall.com/docs/api).
*   **Supporto Completo:** Gestisce comandanti singoli, partner, background e companion.
*   **Due Modalità di Gioco:**
    *   **Modalità Pod:** Genera una griglia 2x2 con le carte dei comandanti, i posti dei giocatori e un banner centrale per il risultato di "Win" o "Draw".
    *   **Modalità Classifica:** Genera una lista verticale per la Top 4, completa di note di testo personalizzate e grandezza del font regolabile.
*   **Esportazione in Alta Qualità:** Esporta il layout generato come PNG ad alta risoluzione (ottimizzato per la condivisione da smartphone).
*   **Interfaccia Moderna:** Un'estetica scura con dettagli neon dorati, ispirata alle moderne grafiche dei tornei cEDH.
*   **Mobile Friendly:** Completamente responsive e progettato per funzionare perfettamente su smartphone.

### 🚀 Come si Usa
1. Scarica o clona questo repository.
2. Apri il file `index.html` (o il nome che hai dato al tuo file unico) direttamente in qualsiasi browser web moderno (Chrome, Safari, Edge, Firefox).
3. Cerca i comandanti, selezionali e clicca sul pulsante **"📸 Genera e Salva"** per ottenere la tua immagine!

*Nessun server, nessun tool di build, nessuna dipendenza richiesta.*

### 🛠️ Tecnologie Utilizzate
*   [HTML5 Canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API) per il rendering del layout e la generazione delle immagini.
*   [Scryfall API](https://scryfall.com/docs/api) per i dati e le immagini delle carte.
*   Vanilla JavaScript & CSS.
